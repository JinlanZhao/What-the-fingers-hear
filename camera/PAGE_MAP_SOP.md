# Page Map SOP

This document describes how to generate, calibrate, and test `data/page_map.json`,
which maps Braille page coordinates to measure numbers.

---

## Overview

Each physical Braille page is photographed through the ArUco registration system,
rectified to a canonical 1100 × 1700 px image, and mapped so that any pixel
coordinate in that image can be looked up to find its measure number.

The mapping chain is:

```
BRF source file
  └─ parse_brf()  →  line ranges per measure (source-level)
       └─ braille_grid_calibration.json  →  pixel coordinates
            └─ page_map.json  →  x1 y1 x2 y2 per region
```

---

## ArUco Page Marker IDs

The following convention is proposed (IDs 10–11 are confirmed in code):

| ArUco ID | Page |
|----------|------|
| 10       | 1 (title) |
| 11       | 2 |
| 12       | 3 |
| 13       | 4 |
| …        | … |
| 27       | 18 |

Formula: `ID = page_number + 9`

**Confirm this mapping before printing ArUco markers for pages 3–18.**
Update `PAGE_MARKER_MAP` in `tools/build_page_map.py` if different IDs are used.

---

## Step 1 — Verify BRF source

```bash
python3 tools/build_page_map.py --verify-only
```

Expected output:
- 18 pages, 18 regions
- Measures 1–16 all present
- Measure 1 spans pages 2–3, Measure 16 spans pages 17–18
- Page 1 has no measure regions

---

## Step 2 — Calibrate grid

Run once per printing/embossing setup. Uses a rectified content-page image
(page 2 is recommended — it has content on all rows).

```bash
python3 tools/calibrate_lines.py --page 2
# or with explicit image:
python3 tools/calibrate_lines.py camera/output/page_02_snapshot_2.jpg
```

A 40-column × 25-row grid overlay appears. Align it so each cell covers one
Braille cell. Row 25 (shown in orange) is the Braille page-number row.

| Key | Action |
|-----|--------|
| Arrow keys | Move grid origin |
| `[` / `]` | Decrease / increase column width |
| `-` / `=` | Decrease / increase row height |
| `S` | Save calibration |
| `R` | Reset to defaults |
| `Q` / Esc | Quit without saving |

Saves: `data/braille_grid_calibration.json`

---

## Step 3 — Build page_map.json

```bash
python3 tools/build_page_map.py
# Skip overlay image generation:
python3 tools/build_page_map.py --no-overlay
```

Saves: `data/page_map.json`

Generates overlay images in `camera/output/` for any page that has a
rectified snapshot available (e.g. `page_02_overlay.jpg`).

---

## Step 4 — Run automated tests

```bash
python3 tools/test_page_map.py
```

All 10 tests must pass before using `page_map.json` in the real-time system.

---

## Step 5 — Click test

Verify visually that pixel coordinates are correct by clicking on a rectified image:

```bash
python3 tools/click_test.py --page 2
python3 tools/click_test.py --page 17 camera/output/page_17_snapshot_1.jpg
```

Click anywhere in the window. Terminal prints:
```
  ( 342,  890) → page=2  measure=1  continuation=1  lines=15–24
  (  50,  200) → None
```

---

## Regenerating after a new print run

If the physical page layout changes (different printer, different margins):

1. Re-run calibration:
   ```bash
   python3 tools/calibrate_lines.py --page 2
   ```
2. Rebuild the map:
   ```bash
   python3 tools/build_page_map.py
   ```
3. Re-run tests:
   ```bash
   python3 tools/test_page_map.py
   ```
